# Contributing

Thanks for helping improve RES Studio.

1. Open an issue describing the bug or proposed change before large contributions.
2. Fork the repository and work on a dedicated branch.
3. Keep changes focused; add regression tests for bug fixes.
4. Run `python -m unittest discover -s tests` and `npm test` from `res-studio/` when dependencies are available.
5. Open a pull request explaining the change, testing, and security implications.

Do not submit secrets, tokens, captured private data, unauthorized target content or exploits targeting third parties. Follow `SECURITY.md` for vulnerability reports.

The maintainers review contributions; a passing CI check is not an automatic approval.
