01 / TOOLKIT
Capabilities

Built for the curious mind.

Focused tools for developers investigating assets and application behavior they are authorized to inspect.

⌁

Asset discovery

Explore accessible HTML, CSS, JavaScript and referenced resources through bounded scans.

⟐

JavaScript analysis

Inspect framework clues, imports, dependencies and code structure with heuristic analysis.

▦

Bundle exploration

Use Webcrack to unpack compatible JavaScript bundles and inspect recovered modules.

◈

Dynamic capture

Optional Chromium capture with a separately configured isolated Docker worker.

⇄

Observable API signals

Study publicly observable requests and responses. Private backend code remains inaccessible.

↗

Portable exports

Keep collected resources and analysis reports in local ZIP or JSON exports.
